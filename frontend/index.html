Frequently Clarified Architectures and implementation details
How does Job Atlas evaluate Field Fill Rate ($FFR$)?

Each JSON payload extracted by the Scraper Studio collector is inspected against five mandatory fields: title, date, city, domain, and summary. The Field Fill Rate is calculated as $FFR = (\text{non-null fields} / \text{total required fields}) \times 100$. If $FFR < 80\%$, collector status shifts to DEGRADED and autonomous healing is queued.

What happens during autonomous self-healing?

When a web target alters its DOM tree, the validator collects missing field key names and triggers bdata scraper heal <collector_id> "<feedback>" via asynchronous subprocess. Once repaired selectors are verified against sample payloads, `bdata scraper approve` promotes the fix to production without manual engineering intervention.

How is the Emergence Score ($S_{emergence}$) computed?

Emergence score is calculated per (City, Domain) bin using a time-decay summation: $S_{emergence} = \sum [ w(\text{type}_i) \cdot e^{-\lambda \cdot t_i} ]$, where $w(\text{type}_i)$ weights high-impact indicators (facility expansions: 3.0, civic zoning: 2.5, research grants: 2.0) and $\lambda = 0.1$ establishes a 30-day half-life decay.

How does Signal Copilot connect text queries to map actions?

Signal Copilot uses OpenAI/Anthropic function calling with defined tool schemas (search_signals, get_emergence_score). Along with natural language synthesis, the response payload returns structured UI action triggers such as ACTION: FOCUS_MAP(city='Pune', zoom=12) or ACTION: PULSE_HUB(city='Bengaluru') to drive interactive dashboard viewports.
